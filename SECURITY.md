# Security Policy

## Scope

This repository is editor configuration: Lua files and a plugin lockfile. It contains no service and no library. In scope:

- A plugin spec or lockfile entry that points at a different or malicious repository
- Config that runs something other than what the guides document
- A setup instruction that would leave insecure file permissions behind

## Out of scope

- A vulnerability in Neovim or in a listed plugin, report that upstream

## Reporting a vulnerability

> [!IMPORTANT]
> Report privately, not in a public issue. Email contact@isaacadjei.me with details and
> reproduction steps. Expect an acknowledgement within a few days.
